## The label

> WARNING: This human will say "I'm five minutes away" while still in bed, wearing no shoes, with no intention of leaving.

A safety warning label for every human being: the universal "I'm five
minutes away" lie, told from bed, escalating in three beats — still in
bed, wearing no shoes, with no intention of leaving — so the laugh lands
in the last few words, in the rhythm of a real printed label.

## How to run

```sh
python3 main.py
```

This writes the label (one line, 120 characters) to `/output/entry.txt`.
Python 3.13, standard library only, no network access, deterministic.
